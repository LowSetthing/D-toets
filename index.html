Object-Oriented Programming (OOP) in C#

Deze cheatsheet helpt je bij de voorbereiding op je d-toets. Bevat C# theorie, codevoorbeelden en een compleet overzicht van UML klassendiagrammen.

1. Basis OOP

Een Klasse (Class) is een blauwdruk. Een Object is een instantie van die blauwdruk. Een Constructor is een speciale methode die wordt aangeroepen wanneer een object wordt aangemaakt (met new).


public class Auto 
{
    // Attributen (velden)
    public string Merk;
    public int Bouwjaar;

    // Constructor (Zelfde naam als de class, geen return type)
    public Auto(string merk, int bouwjaar) 
    {
        this.Merk = merk;       // 'this' verwijst naar het huidige object
        this.Bouwjaar = bouwjaar;
    }

    // Methode (Gedrag)
    public void Starten() 
    {
        Console.WriteLine($"{Merk} is gestart.");
    }
}

// Gebruik:
Auto mijnAuto = new Auto("Toyota", 2020); // Object aanmaken
mijnAuto.Starten();

3. Properties & Fields

Gebruik properties in plaats van public fields om controle te houden over get/set acties. Dit heet data hiding.


public class Persoon 
{
    // Field (Backing field), altijd private
    private int _leeftijd; 

    // Full Property
    public int Leeftijd 
    {
        get { return _leeftijd; }
        set 
        { 
            if(value >= 0) // Validatie
                _leeftijd = value; 
        }
    }

    // Auto-Implemented Property (C# maakt op de achtergrond een private field aan)
    public string Naam { get; set; }

    // Read-only Property (Alleen get, waarde zetten via constructor)
    public string BSN { get; private set; }
}

4.1 Encapsulatie (Data Hiding)

Het samenvoegen van data (fields) en methodes (gedrag) in één eenheid (class) en het afschermen van interne staten via access modifiers (private fields + public properties/methodes). Dit voorkomt dat objecten in een ongeldige staat raken.

4.2 Overerving (Inheritance)

Subklassen (child) nemen eigenschappen en methoden over van een basisklasse (parent) via de dubbele punt :. Gebruik het keyword base om naar de basisklasse te verwijzen.


public class Dier 
{
    public string Naam { get; set; }
    
    public Dier(string naam) 
    {
        Naam = naam;
    }
}

// Hond 'is een' Dier
public class Hond : Dier 
{
    public string Ras { get; set; }

    // Roep constructor van basisklasse aan met 'base(...)'
    public Hond(string naam, string ras) : base(naam) 
    {
        Ras = ras;
    }
}

4.3 Polymorfisme

"Vele vormen". Subklassen kunnen methoden van hun basisklasse overschrijven (override) mits de basisklasse dit toestaat (virtual).


public class Dier 
{
    // 'virtual' betekent: mag overschreven worden
    public virtual void MaakGeluid() 
    {
        Console.WriteLine("Dier maakt een geluid");
    }
}

public class Kat : Dier 
{
    // 'override' vervangt de implementatie van de basisklasse
    public override void MaakGeluid() 
    {
        Console.WriteLine("Miauw!");
    }
}

// Polymorfisme in actie:
Dier mijnDier = new Kat();
mijnDier.MaakGeluid(); // Output: Miauw! (Omdat het runtime object een Kat is)

4.4 Abstractie (Abstract Classes & Interfaces)

Abstract Class

Kan niet geïnstantieerd worden (geen `new`). Dient puur als blauwdruk. Kan zowel uitgewerkte als abstracte methodes bevatten.


public abstract class Vorm 
{
    // Abstracte methode (geen body)
    public abstract double BerekenOppervlakte();
    
    // Gewone methode is ook mogelijk
    public void PrintInfo() { ... } 
}

Interface

Bevat alleen methodespecificaties (geen implementatie/data). Een class kan meerdere interfaces implementeren (meervoudige overerving nabootsen).


public interface IBeveiligd 
{
    // Geen access modifiers (altijd public)
    void LogIn();
    void LogUit();
}

public class Systeem : IBeveiligd 
{
    public void LogIn() { ... }
    public void LogUit() { ... }
}

5. Extra's

  • static: Hoort bij de klasse zelf, niet bij een instantie (object). Je roept het aan via de klassenaam: Math.PI. Static methodes kunnen geen instance members (this.) gebruiken.
  • struct: Value type (zoals int, bool). Wordt op de stack opgeslagen i.p.v. de heap. Goed voor kleine datastructuren (zoals een X,Y coördinaat). Ondersteunt geen overerving.
  • record (C# 9+): Reference type dat geoptimaliseerd is voor onveranderlijke (immutable) data en value-based equality. 
    public record Persoon(string Naam, int Leeftijd);

6. UML Klassendiagram Cheatsheet

De Klasse (Notatie)

Een klasse wordt weergegeven als een rechthoek met 3 compartimenten:

Auto
<<abstract>>
- merk: string
- bouwjaar: int
# snelheid: double
+ Starten(): void
+ Remmen(kracht: int): bool
_ GetAantalAutos(): int
  • Formule Attribuut: modifier naam : type
  • Formule Methode: modifier naam(param: type) : returnType
  • Cursief = abstract (zowel naam als methode).
  • Onderstreept = static.

Relaties (Pijlen)

Hoe klassen met elkaar verbonden zijn. (Links is subclass/afhankelijk, rechts is basisklasse/target).

Generalization (Overerving) Class ➞ Basis class ("Is-een"). Dichte lijn, open driehoek.
Realization (Interface) Class ➞ Interface. Stippellijn, open driehoek.
Association (Directe associatie) Class heeft referentie naar andere Class. Dichte lijn, open pijl (soms zonder pijl).
Aggregation (Aggregatie) "Heeft een" (Zwak). Deel kan onafhankelijk bestaan (bv. Team <>-- Speler). Open ruit aan kant van het geheel.
Composition (Compositie) "Bestaat uit" (Sterk). Deel sterft als geheel sterft (bv. Huis ◆-- Kamer). Dichte ruit.

Multipliciteit (Kardinaliteit)

Wordt geschreven bij de uiteinden van de associatielijnen (bijv. 1, 0..1, * of 0..*).
Voorbeeld: Een Klant(1) heeft Bestellingen(0..*).
